PhysiBoard is a physical-keyboard-first input method for Android, tuned for the Unihertz Titan 2 Elite. It is a fork of Pastiera by PalSoftware, adding a focused set of hardware-keyboard features on top of that engine.

Fork highlights:
- Hold the Fn key in any text field to start voice dictation (adjustable end-of-speech pause, profanity masking, haptic cues).
- Smart keyboard backlight that stays lit in the dark past the vendor's 30-second cap, driven in-app with no companion app and no root.
- A clean terminal-style UI and an action-surface home screen that only shows what needs attention.
- Sensible out-of-box defaults and a two-step setup.

Inherited from Pastiera:
- Long-press mappings and configurable modifier behavior.
- A navigation/shortcut layer and physical-key cursor gestures.
- Customizable keyboard layouts and symbol pages with JSON import/export.
- Clipboard history, user dictionaries, suggestions, and autocorrection.
- Full backup and restore of settings and custom data.
